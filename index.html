Featured project

Film Finder

Full stack·Next.js 16·PostgreSQL

A film discovery app that works out what you like from what you already love. Pick five to ten favourites and it ranks the rest of the catalogue by how much genre DNA they share — with a match percentage and the genres you have in common.

The recommender is a pure function with unit tests: it builds a genre profile from your favourites, scores candidates by cosine similarity, and breaks ties on TMDB rating then ID so results are deterministic rather than shuffling between loads. No ORM — plain SQL through pg with a 40-line migration runner, which keeps the upserts and locking where you can see them. The ten-favourite cap survives concurrent requests because addFavourite locks the user’s row inside a transaction before counting. Sessions are HS256 JWTs in httpOnly, SameSite=Lax cookies, and login compares against a dummy hash for unknown emails, so response time doesn’t reveal which accounts exist.

What you're looking at The plate is drawn procedurally — there's no photograph anywhere on this page. Every knob you move rewrites 360,000 pixels before the next frame, which is the honest version of what a colour grade is: not a mood, a function. Try Day for night, then read the code underneath and find the line that does it. 
// the whole grade — applied per pixel, every frame
function grade(r, g, b, p) {
  const gain = 2 ** p.exposure;          // exposure is stops, so it's a power of two
  r *= gain * (1 + p.temp); g *= gain; b *= gain * (1 - p.temp);
  const px = v => (v - 0.5) * p.contrast + 0.5;  // contrast pivots on mid-grey
  r = px(r); g = px(g); b = px(b);
  const y = 0.2126*r + 0.7152*g + 0.0722*b;    // Rec.709 luma
  r = y + (r - y) * p.sat; g = y + (g - y) * p.sat; b = y + (b - y) * p.sat;
  const lift = v => v + p.lift * (1 - v) ** 2;   // lift only touches the toe
  return [lift(r), lift(g), lift(b)].map(v => clamp(v, 0, 1));
}
